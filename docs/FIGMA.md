## Project scope

This project covers only the Buyamia mobile application.

The website contained in the same Figma file is completely out of scope.

Do not implement:

- desktop website screens;
- marketing website pages;
- desktop headers;
- desktop footers;
- website navigation;
- website-specific sections;
- website-specific layouts.

Only mobile application frames should be analyzed and implemented.
