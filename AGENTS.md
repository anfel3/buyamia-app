# Buyamia Mobile App Rules

- Read the exact versioned Expo docs at https://docs.expo.dev/versions/v57.0.0/ before writing Expo code.
- Figma is strictly read-only.
- Build the mobile application only.
- Never implement desktop or website frames.
- Use React Native only.
- Do not add HTML or CSS files.
- Do not use full-screen screenshots as UI.
- Build reusable components.
- Never commit or push automatically.
